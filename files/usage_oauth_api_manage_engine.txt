curl -X POST "https://accounts.zoho.in/oauth/v2/token"   -d "code=" -d "client_id=" -d "client_secret=" -d "grant_type=authorization_code"

The Above will give a response with a refresh token

curl -X POST "https://accounts.zoho.in/oauth/v2/token"   -d "refresh_token=" -d "client_id=" -d "client_secret=" -d "grant_type=refresh_token"

The above will give a response with access token, use that and include it below for all the operations listed
